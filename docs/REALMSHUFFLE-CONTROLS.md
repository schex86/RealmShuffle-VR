# RealmShuffle VR 0.7.2 controls

The custom controller mappings apply during RealmShuffle playback. Original Immivio controls may still apply in menus.

| Left controller | Action |
| --- | --- |
| X | Pause/resume video only |
| Y | Toggle automatic scene advancement |
| Trigger | Synchronize music with current scene; repeat to select another matching variant |
| Grip | Toggle performance overlay |
| Thumbstick left/right | Change binaural beat frequency |
| Thumbstick up/down | Change binaural beat volume |
| Thumbstick press | Next independent music track |

| Right controller | Action |
| --- | --- |
| A | Next scene |
| B | Previous scene |
| Trigger | Menu |
| Grip | Adjust view |
| Thumbstick left/right | Seek |
| Thumbstick up/down | Zoom |
| Thumbstick press | Recenter view |

Viewing orientation and zoom persist between scenes within a session. Binaural frequency labels describe intended listening modes, not proven medical effects. Use a comfortable listening volume.
