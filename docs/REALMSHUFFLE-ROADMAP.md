# RealmShuffle roadmap

| Version | Milestone | Status |
| --- | --- | --- |
| 0.7.2 | Adaptive shuffle, independent music, scene synchronization, binaural audio, transitions, viewing controls and performance overlay | Published source; tested on Quest 3 |
| 0.7.3 Lite | Persistent local playback journals and panorama optimization | Source published; startup and journal checks passed; further acceptance pending |
| 0.7.4 | Music history, track selection, natural media titles, simplified controller guide and journal corrections | Planned |
| 0.7.5 | Preference analysis using playback and navigation history | Planned |
| 0.7.6 | Independent native source build | Proposed |
| 0.7.7 | Remove unnecessary application features | Proposed |
| 0.7.8 | Further APK and dependency optimization | Proposed |
| 0.8.0 | Optional cloud media catalog | Planned |
| 0.8.1 | Intelligent prefetching and cloud playback | Planned |
| 0.8.2 | Configurable offline storage budget and verified offloading | Planned |
| 0.8.3 | Expanded VR library interface | Planned |

Future cloud functionality should use user-authorized storage, protect active and pinned media, verify integrity before removing local copies, and retain offline playback. No cloud integration or preference-based deletion is enabled in 0.7.3 Lite. Roadmap versions are proposals, not delivery commitments.
